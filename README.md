# Energy Demand Intelligence Platform

An end-to-end cloud data engineering and analytics platform for
electricity demand monitoring, forecasting, and anomaly detection.

## Planned Architecture

EIA API
→ Azure Data Factory
→ Azure Data Lake
→ Bronze
→ Silver
→ Gold
→ Microsoft Fabric / Databricks
→ Power BI

## Project Goals

- Build a cloud-based data ingestion pipeline
- Implement Medallion Architecture
- Process data using Spark/PySpark
- Perform data quality checks
- Detect unusual electricity demand patterns
- Forecast short-term electricity demand
- Build an analytics dashboard
